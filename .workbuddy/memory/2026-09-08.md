## 大模型名称配置（只读盘点）

- **项目没有预置任何模型**：V1–V7 migration 中 `ai_provider` / `ai_model` 完全没有 INSERT
  （只有 `app_role`、`user_storage_usage` 有种子数据）；`.env.example` 的 default model 是占位符。
- 模型名必须在**两处**配置：
  1. `stardust_ai/.env` → `STARDUST_AI_OPENAI_COMPATIBLE_DEFAULT_MODEL`（fallback + `/health` 的 provider_configured 判定）
  2. 数据库 `ai_provider` + `ai_model` 两行（前端下拉读 `GET /api/v1/ai/models`；不插则显示 "No model configured"）
- 调用链：Spring 传 `ai_model.external_model_id` → Python `ChatRequest.model`；
  Python `_resolve_model` 用 request.model 优先，缺失才回退 DEFAULT_MODEL。
- 真正生效的 base_url 是 Python `.env` 里的；数据库 `ai_provider.base_url` 目前只是元数据，不参与实际调用。
